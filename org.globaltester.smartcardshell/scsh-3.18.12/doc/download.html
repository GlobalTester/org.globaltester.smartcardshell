Download

The Smart Card Shell is provided as IzPack installer and as a zipped file archive. The IzPack installer can be used on Windows, Linux and MacOS systems and is supplied as a self-contained jar archive. Just double-click on the jar file or enter java -jar scsh3.x.y.jar.

The zipped file archive contains a ready to run setup. Just unpack on your disk and start the application with the provided .exe, .cmd or shell files.

The second zip contains a bundled Java 17 JRE for Windows 64.

Latest stable version is 3.18.12

  • IzPack Installer (.jar, 18MB)
  • File Archive (.zip, 18MB)
  • File Archive with bundled Java 17 JRE(.zip, 60MB)

See CHANGES for the list of things that changed in this release.
